# Glowfathom

An original deep-sea idle game for the web browser. You pilot a research sub,
tap glowing creatures to scan them, build a fleet that keeps earning while you
are away, and dive through five ocean zones to the bottom of the trench.

It was built to be a small, hands-off source of income: static files with no
server, no running cost and no runtime dependencies, listed where players and
payouts already exist.

## What to expect

Honest numbers first. Research for this project found no verified case of a
product earning money with no audience and no ongoing work. For this game the
most likely first-year result is **nothing**. There is roughly a one-in-five
chance that any money at all reaches PayPal, and a smaller chance of a
recurring monthly amount if a web-game portal promotes it. It costs nothing to
leave running.

## How it can earn

| Where | How | Into PayPal |
|---|---|---|
| itch.io | Free to play, optional "pay what you want" | Payout on request from US$5 |
| CrazyGames | Share of advertising income, after a trial with real players | Monthly from 100 euros, where offered |
| GameDistribution | Share of advertising income across small game sites | From 50 euros |
| GitHub Pages copy | Tip link to Ko-fi | Straight away |

The steps that only a person can do (accounts, identity checks, the first
upload) are in **[docs/SETUP.md](docs/SETUP.md)**. Store text to copy and paste
is in [docs/LISTINGS.md](docs/LISTINGS.md).

## What is automated

Every push to this repository:

1. type-checks the code, runs the unit tests and the pacing simulations;
2. builds one zip per storefront;
3. runs the game in a real browser and plays it;
4. publishes to GitHub Pages and to itch.io, once each has been switched on.

Nothing runs on a schedule and nothing needs renewing.

## Working on it

```bash
cd game
npm ci
npm run dev        # http://127.0.0.1:5173, rebuilds on change
npm run check      # type-check, unit tests, build, browser tests
npm run build      # dist/<target>/ and dist/zips/*.zip
npm run store-assets   # remake the covers, screenshots and videos in store/
```

Build targets: `web` (GitHub Pages or any host), `itch`, `portal` (plain zip
for a CrazyGames trial), `crazygames` (with their SDK), `gamedistribution`.

| Path | What it holds |
|---|---|
| `game/src/game/` | The rules: content tables, formulas, actions, saves, and a simulator that plays the game to check its pacing |
| `game/src/live/` | The live scene: creatures, taps, the shoal event |
| `game/src/render/` | Everything drawn on the canvas, all generated by code |
| `game/src/ui/` | The interface |
| `game/src/audio/` | Sound, synthesised at run time |
| `game/src/platform/` | One adapter per storefront |
| `game/scripts/` | Build, pacing fit, store images |
| `game/e2e/` | Browser tests |
| `game/store/` | Covers, screenshots and preview videos for listings |

Pacing is not hand-tuned. `game/scripts/fit-surveys.ts` plays the real rules
with a simulated player and sizes each depth's survey so the game follows a
chosen schedule; `game/src/game/balance.test.ts` fails if a change makes the
game rush, drag or stall.
